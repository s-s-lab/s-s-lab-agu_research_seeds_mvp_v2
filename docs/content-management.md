# コンテンツ管理

## 基本方針

研究シーズは`src/content/seeds/`配下のJSONファイルで管理します。1件につき1ファイルとし、ファイル名は`seed-001.json`のようにIDと対応させます。

## 追加手順

1. サイトの`#/data-editor`を開きます。
2. 「新規登録」を押し、必須項目を入力します。
3. 画像を使う場合は`thumbnail`と`images`に`media/seeds/{seed-id}/...`形式で指定します。
4. JSONをダウンロードします。
5. GitHubで`src/content/seeds/`へ追加します。
6. Pull Requestを作成し、検証結果を確認します。

## 修正手順

既存JSONをダウンロードまたはコピーし、データ編集支援ページで読み込んで修正できます。修正後のJSONを同じファイル名で置き換えてください。

## 注意点

- 実在する研究者、所属、メールアドレスを推測して追加しないでください。
- 公開前に研究者本人または担当部門の確認を行ってください。
- 画像の利用許諾、個人情報、未公開研究情報の扱いを確認してください。
- `status`を`draft`にすると公開画面には表示されません。
