# デザインガイドライン

## 基本方針

- 白を基調に、落ち着いたブルー・ネイビーをアクセントにする
- 研究シーズ情報と検索を主役にする
- 装飾を増やしすぎず、行政システムのように堅くなりすぎない
- カード、フォーム、ボタンの角丸と影は控えめにする
- PC、タブレット、スマートフォンで横スクロールを発生させない

## アクセシビリティ

- 見出し階層を保つ
- フォームにはlabelを付ける
- focus-visibleを明確にする
- 画像にはaltを設定する
- 色だけに依存せず、ラベルやテキストで状態を示す
- `prefers-reduced-motion`に配慮する

## 画像

正式な大学ロゴがリポジトリにない場合、ロゴ画像を作成しません。サイト名はテキストで表示します。研究シーズ画像は`public/media/seeds/`配下で管理します。
